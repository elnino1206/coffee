# Версии вёрстки

| Папка | Что это | Статус |
|---|---|---|
| `v1-static/` | Статичная вёрстка по макетам: UI-кит, каталог, карточка товара, подписка, ЛК, чекаут. WebP, ленивая загрузка, разобранные ассеты. | **Заморожена.** Не править — эталон для сравнения. |
| `v2-anim/` | Рабочая копия. Сюда идёт анимация по [`docs/animation-plan.md`](../docs/animation-plan.md). | В работе |

Обе версии самодостаточны: открываются как статика, без сборки и зависимостей.

## Локальный просмотр

Обе можно поднять одновременно и сравнивать в соседних вкладках:

```bash
python -m http.server 5555 --directory versions/v2-anim
```

```bash
python -m http.server 5556 --directory versions/v1-static
```

Конфигурации `v2-anim` и `v1-static` прописаны в `.claude/launch.json`.

## Общее для всех версий

Лежит в корне репозитория, не дублируется по версиям:

- `brand/` — мастер-файлы логотипа и исходные JPG фотографий (из них собраны WebP).
- `docs/` — план анимации и прочая проектная документация.
- `inst_designe/` — ТЗ и дизайн-документация.
- `01–13.jpg`, `basic.jpg` — макеты экранов и UI-кит.
